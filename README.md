# Taskeasy Manager v1.0.1

## Information

### About the Program

This program is a simple Task Manager. I created it to organize my daily task list and keep everything organized.

I made a simple interface for better understanding. In the first window, there are just two buttons: **Create New Task Project** and **Load Task Project**.

If you create a new task project, a small window will appear with a text box where you can set your project name. If you click **Load Project**, the file explorer will appear so you can choose your `.tasman` file (the save file format).

### How to Use

* When you open the program, two buttons will appear. If you press the **Create** button, a window will appear where you can set the project name. However, if you press the **Load** button, the file explorer will open. There, you can choose your project, and it will be opened.

* When you open the project window, you can create a new task, delete a task, or randomly choose one. The **Create** button will create a new task. The **Delete** button will delete the selected task. The **Random** button will randomly choose a task for you to do. And the **Save** button will save the project.

### Technical Details

The program was created using the C# programming language and the Avalonia framework.
